# Block 8 presentation

Open **index.html** in a browser. The 14-slide presentation works offline with local screenshots, CSS and JavaScript; no app server, database or login is required. Keep this folder together when copying it.

- `index.html`: audience slides, without presenter notes.
- `speaker-notes.md`: narration, decision explanations, source references and demo checklist.
- `presentation.css`, `presentation.js`: design and slide controls.
- `assets/`: local restaurant background and fictional screenshots rendered from the application templates.

Use Left/Right or Page Up/Page Down to navigate, Home/End for first/last, or the compact slide selector to jump. Press C to toggle controls, Escape to hide them. Print / PDF opens the browser print dialog. For projection, use browser fullscreen. No script text or notes are revealed by these controls.

The screenshots use fictional data and do not demonstrate real mail delivery. Live demo preparation is documented in [speaker notes](speaker-notes.md) and [the authentication guide](../docs/block8-authentication.md).

The old presentation is preserved in [archive/presentation-block5](../archive/presentation-block5/README.md). It is historical material. The previously prepared Block 8 submission folder and ZIP have not been rebuilt by this presentation task.
